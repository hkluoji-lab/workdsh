# 0.1.0-alpha.23

- 为认证 Fetch 管理请求增加明确超时，并把取消与超时映射为稳定客户端错误。
- 导入文件读取、上传、预检与确认安装共用可中止操作；界面提供取消上传和取消安装入口。
- Host 在导入遍历、内容指纹、复制和原子发布边界检查 AbortSignal；发布前取消不会产生安装目标，暂存凭据仍可重试。

# 0.1.0-alpha.22

- 增加批量启用、停用和可恢复卸载，逐项返回成功与失败并保留失败选择。
- 增加可扩展的 Host 依赖检查契约；卸载前显示依赖影响，以 revision 防止确认后依赖变化，并阻止仍有强依赖的卸载。
- 增加“受管导入含资源 → 冷启动新进程 → 官方 Skill 工具调用”的组合验收。
- 修复卡片管理菜单被相邻卡片遮挡，以及导入完成后旧弹框遮罩残留的问题。

# 0.1.0-alpha.21

- `skill-creator` 改用 Harness 官方 `defineTool` 注册的 Host 草稿、校验、发布工具；发布要求精确草稿修订和用户确认，不再指导模型直接写官方目录。
- SkillManager 持久化私有草稿，发布时重新校验、全局查重、原子写入并回读核对。
- 全局列表展示无效本地技能及可修复诊断，修复保存后重新进入官方发现和调用链。

# 0.1.0-alpha.20

- 技能导入按全局名称取得跨进程锁，并检查所有官方根、扁平文件、目录技能及其他已注册提供方，拒绝同名遮蔽。
- 暂存收据与安装副本使用完整文件内容指纹复核，拒绝预检后的同长度篡改。
- 回归覆盖跨根冲突、并发确认单胜者和 Host 重启后继续确认。

# 0.1.0-alpha.19

- 增加 `.zip`、`.md` 和文件夹的浏览器上传、Host 预检、显式确认、失败重试与过期清理。
- 上传复用 Harness Connection 的认证流式 Fetch 扩展面，安装进入官方技能根并由官方 provider/watcher 发现。

# 0.1.0-alpha.18

# 0.1.0-alpha.17
